Token Radar ranks all 225 pre-token protocols in a sealed DeFiLlama snapshot by implied token value — TVL times a peer multiple taken from the live-token protocols in the same category, adjusted for 7-day growth, maturity and chain breadth — with a concrete 7-step farm plan for each, a filterable dashboard, and a model lab that re-ranks the board live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
